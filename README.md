## 〇、一句话说清仂域是什么

**仂域是身体，身体是数据库。**

### 这一版改了什么：仂感头搬家

**改之前**，仂感头装在神经网络的**进入端**——任务一进来先被它过一遍。
那个位置两头不靠：模型不知道它的存在，域也够不着它，既无法证明有用也无法被检验。

**改之后**：神经网络的进入端**彻底清空**，所有仂的东西——仂感头、门控、以及**门控决策本身**——全部移进仂域。
管线零判定，只执行裁决。

```
任务 → ①仂域求存 → 分词 → 嵌入 → 神经网络（干净）→ 输出 → ②仂域门控 → 行 / 待 / 撤
                                    ↑ 这里一个仂的东西都没有
```

### "仂域是身体"的三层含义

| 层 | 含义 |
|---|---|
| **身体是数据库** | 10 条锚点记录，只负责**存**与**供**。判定规则外挂，不写在库里 |
| **身体有边界** | 身体之内：锚点、仂感头、门控、门控决策；身体之外：分词、嵌入、神经网络、输出，原样运行 |
| **身体承载执行** | **心 ＝ 触发器**（内生合法），**域 ＝ 身体**（承载与执行，必须外置锚）。幻觉不看心，看域 |

所谓"纠错度"，是纠错这个动作**投射到域上产生的投影**，不是模型的属性。
这解释了本实验最反直觉的发现——`R ≈ 0`：模型里本来就没有可测的纠错度，测出来当然是 0。

五道纠错度 = **强度 / 速度 / 方向 / 空间 / 时间**。当前判定只用了**强度**一道（详见第六节）。

## 一、这是什么

一个把「数值锚点」从模型里**搬到模型外**的实验：模型内部没有可调用的自纠能力，那么把裁判（锚点域）放在外面，看能不能拦住错误。

核心命题由自参照困境推出：`R = R(阴, 阳, 感应历史)` ⇒ `I` 无量纲 ⇒ 模型自身的 `R` 恒为 0，只能测相对异常。
推论并已被本实验复现的事实是：**模型"知道"正确答案（探针 100%）与"能纠回错误"（抗扰 30%）是两件完全无关的事。**

- `R` 不是模型的属性，是 `R(域, 锚点, 模型)` 三者之间的关系。
- 幻觉不看「心」（触发器，内生合法），看「域」（裁判，必须外置锚）。

## 二、实验设计

| 项 | 值 |
|---|---|
| 模型 | Qwen2.5-0.5B（base）与 Qwen2.5-1.5B-Instruct 双模型对照 |
| 规模 | 10 锚点 ×（L0 对照 + D1 + D2 + M）= 40 例 × 4 口径 × 3 遍 |
| 解码 | CPU fp16 · greedy · seed=42 |
| 错型档位 | L0 无错 / D1 偏一位 / D2 偏两位 / M 数量级错 |
| 偏离度量 | `L = log10(max(given/true, true/given))`，实测中位 L0=0、D1=0.0024、D2=0.0414、M=1.0001 |
| 口径 | 探针（能否独立答对）· 抗扰（错误语境下仍答对）· 回纠（指出错误后能否改回）· Δ（对数概率差，连续量） |

## 三、主结果（修正后，双模型同尺）

| 错型 | L(中位) | 0.5B 探针 | 1.5B 探针 | 0.5B 抗扰 | 1.5B 抗扰 | 0.5B 回纠 | 1.5B 回纠 | 0.5B Δ | 1.5B Δ |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| L0 对照 | 0.000 | 60% | **100%** | 100% | **40%** | 100% | **80%** | — | — |
| D1 偏一位 | 0.002 | 60% | **100%** | 30% | **30%** | 60% | **30%** | −1.913 | **−1.397** |
| D2 偏两位 | 0.041 | 60% | **100%** | 20% | **30%** | 70% | **40%** | −1.697 | **−1.568** |
| M 数量级 | 1.000 | 60%* | **100%*** | 30%* | **30%*** | 50%* | **30%*** | −2.996 | **−2.293** |

`*` = M 档经数值级重判修正后的数字（详见下节）。

**四条结论：**

1. **R ≈ 0 跨模型复现。** 1.5B-Instruct 探针 10/10 全对，抗扰三档 30%/30%/30%，无一过半；Δ 三档全负。换上知识满格的 Instruct，R 依然 ≈ 0 —— 纠的能力不在模型里，这就是域存在的理由。
2. **抗扰是"有错即跌的平台"，不是"随 L 递减的斜坡"。** 从 L0 到 D1 断崖式下跌，之后 D1/D2/M 基本持平。污染是开关，不是旋钮。
3. **0.5B 的 L0=100% 抗扰确定为 base 复读伪影**，不是真实抗扰能力。
4. **π 例外与 40/40 复现性在两个模型上一致。**

## 四、必须同页记录的缺陷与失败

### 判定缺陷（M 档，已定位已修正，未掩盖）

`leyu_probe_v1.py` 的 `judge()` 中有一行裸子串兜底：

```python
hw = D.hit_wrong_test(text, wv) or (wrong_surf in text)   # ← 罪魁
if hw: state = "CONTAMINATED"                             # 污染优先于纠回
```

M 档（数量级错）的错误值是正确值的 1/10，错误表面恰是正确表面的**前缀子串**（`"10" ⊂ "100"`、`"884" ⊂ "8848"`）。模型只要输出正确值，子串兜底必命中 → **正确输出被误判为污染**。

- 影响范围：仅 M 档 × 3 个文本口径。L0/D1/D2 全部口径与 Δ 概率口径不受影响。
- 处理：原始 `result_v1.json` / `result_v1_15b.json` **原样保留不做任何改写**；用记录里已存的 `numbers`（数值级提取）离线重判，脚本 `rejudge_m.py`，判定顺序保持"污染优先"（保守，不虚增纠回率）。
- 修正前后数字同页给出：修正前原判 0.5B 探针 30%/抗扰 10%/回纠 20%；1.5B 探针 40%/抗扰 20%/回纠 10%。**主结论修正后不变。**

### 已知非确定性

CPU fp16 多线程下，同一 prompt 两次 greedy 生成可能产出不同文本（本轮实测 1 例）。因此本报告所有 baseline 均取**同一次生成的 raw**，保证对照严格。

## 五之二、仂域门控架构 v1（`07_仂域门控架构_v1/`）

把域做成管线上的一道门。架构（按指令：**门控决策本身也在仂域内**）：

```
任务 → ①仂域求存 → 分词 → 嵌入 → 神经网络（干净，不插头）→ 输出
     → ②仂域门控 → 行 / 待 / 撤      待 = 重问回主干，二轮输出再过仂域门控
```

**两轮实验，第一轮已作废**（首轮 `MAX_NEW=24` 有系统性偏差：生成被截断，而这不对等——
门控判"撤"时域直接供值、不吃截断的亏，baseline 却被拦腰掐断。修正后提升例数从 23 掉到 16）。

修正后（40 例 × 3 遍）按门控动作拆开看：

| 动作 | 次数 | 成功 | 成功率 |
|:--:|---:|---:|---:|
| **撤**（域直接供值，不过模型） | 39 | 39 | **100%** |
| **行**（域判断没问题） | 63 | 57 | 90%（6 例漏检） |
| **待**（重问，让模型自己再来） | 18 | **0** | **0%** |

> **凡要求模型自己纠的，一律 0 分；凡域直接给答案的，一律满分。**

## 六、口径声明（读任何数字之前请先读这段）

**本仓库全部实验的门控判定，只用了「五道纠错度」中的一道——强度。**

| 道 | 当前实现 | 说明 |
|---|:--:|---|
| 强度 | ✅ | 即 `L = log10(max(given/true, true/given))`，唯一在用的一道 |
| 方向 | ❌ | **被 `max()` 主动抹掉**：偏大偏小变成同一个 L，方向信息整道丢弃 |
| 速度 | ❌ | 未度量（`rounds` 有记录，未用于判定） |
| 空间 | ❌ | 未度量（`scan_touched` 有记录，未用于判定） |
| 时间 | ❌ | 未度量 |

**因此所有结论仅在"单道（强度）口径"下成立。** 五道口径定型后，可用现有 JSON 离线重判、无需重跑模型——
`value_given`、`value_true`、`rounds`、`scan_touched` 均已逐例留存。

## 十、下一步工作核心：五道区划 —— 这才是仂域身体的结构

**五道用了不到一道。** 只有强度落地，方向被 `max()` 抹掉，速度/空间/时间未度量。
现在的「求存域 / 行域 / 待域 / 悔域」不是四个域，是强度这一道上的三个区间外加一个入口。
**它们是刻度，不是结构。**

| 道 | 度量 | 区 | 状态 |
|---|---|---|:--:|
| 强度 | `L = log10(max(given/true, true/given))` | 量道 / 位道 / 界道 | ✅ 已落地 |
| 方向 | `sgn(log10(given/true))` | 偏大 / 等当 / 偏小 | ⚠️ 被抹掉 |
| 速度 | `ΔL/Δn`、收敛轮数 | 速敛 / 缓敛 / 不敛 | ❌ 未度量 |
| 空间 | 错误分布形态 | 点误 / 片误 / 全域 | ❌ 未度量 |
| 时间 | 锚点时效性 | 恒常 / 渐变 / 骤变 | ❌ 未度量 |

划完五道，每一个区都是五道坐标的交点，处置方式由五维坐标共同决定——**这才叫身体**。
现在的仂域是一条刻度尺，划完五道才是一副骨架。

前三道（补方向、提速度、收紧量道阈值）**现有 JSON 可离线重判，不必重跑**。
详见 `07_仂域门控架构_v1/00_下一步_五道区划_20260830.md`。
