# 「仂庸」—— 五道区划：这才是仂域身体的结构

> 2026-08-30 ｜ 中和道化论 · 「仂庸」 ｜ 作者：何一
> 本文说明**下一步工作的核心**：把仂域里五道投射的各个区划分出来。
> 在此之前的所有实验，都只用了一道。

---

## 一、先说清楚现在缺什么

仂域是身体。但到目前为止，这个身体只有**一条轴**。

强度一道的落地是 `L = log10(max(given/true, true/given))`，然后按阈值切三段：

| 段 | 阈值 | 门控动作 |
|---|---|---|
| 量道 | `L < 0.003` | 行 |
| 位道 | `0.003 ≤ L < 1` | 待 |
| 界道 | `L ≥ 1` | 撤 |

现在说的"求存域 / 行域 / 待域 / 悔域"，**不是四个域，是强度这一道上的三个区间外加一个入口**。它们是刻度，不是结构。

一个只有刻度的身体称不上身体——那是一把尺，不是一副骨架。

**五道是：强度、速度、方向、空间、时间。** 它们是"纠错"投射到仂域上的五个维度，不是模型的属性。这一点必须先钉死：模型自身 R = 0，五道测的是域上的投影，不是模型的能力。

### 当前的缺失清单

| 道 | 状态 | 缺什么 |
|---|:--:|---|
| 强度 | ✅ 已落地 | 唯一在用的一道 |
| 方向 | ⚠️ 被主动抹掉 | `max()` 把偏大与偏小压成同一个 L |
| 速度 | ❌ 未度量 | 无收敛性判据 |
| 空间 | ❌ 未度量 | 无错误分布判据 |
| 时间 | ❌ 未度量 | 无锚点时效判据 |

**五道用了不到一道。** 现有的 69.2%（撤）与 0%（待）都是在这一道半上跑出来的。

---

## 二、五道各自的投射与区

每一道都在仂域上投射出一条轴，每条轴按性质切出若干"区"。区是处置单元的同类——同一个区里的错误，用同一种方式处理。

### 1. 强度道（已有）

- **度量**：`L = log10(max(given/true, true/given))`
- **区**：量道区（`L<0.003`）/ 位道区（`0.003≤L<1`）/ 界道区（`L≥1`）
- **处置**：行 / 待 / 撤
- **已知问题**：量道阈值 0.003 太松。黄河 5461 vs 5464（L=0.0002）被放行，6 例漏检由此而来。

一道划三区，这是现有全部。

### 2. 方向道（被抹掉，须补回）

- **度量**：取符号而非绝对值——`sgn(log10(given/true))`，或记为 `L± = ±L`
- **区**：偏大区（given > true）/ 偏小区（given < true）/ 等当区
- **为什么必须分**：偏大与偏小是两种病，治法相反。
  - 偏大 → 需要**收**（下压，减去虚高）
  - 偏小 → 需要**放**（上抬，补足缺口）
- **代价**：`max()` 把两者压成同一个 L，方向整道丢失。这是当前最便宜的一处修复——**现有 JSON 可离线重判，不必重跑 40×3**。

### 3. 速度道（未度量）

- **度量**：纠错过程中 L 随轮次的变化率 `ΔL/Δn`，或收敛所需轮数
- **区**：速敛区（一两轮到位）/ 缓敛区（多轮趋近）/ 不敛区（越纠越远或原地不动）
- **为什么关键**：这一道直接解释"待 = 0%"。18 遍重问一次没救回，不是重问的姿势不对，是这些例**落在不敛区**——不敛的东西，问多少遍都是零。
- **数据已在手**：每例跑了 3 遍，同一例 3 遍的 L 序列就是速度的原始材料，可离线提取。

### 4. 空间道（未度量）

- **度量**：错误在表征空间里的分布形态——孤立点、连成片、还是全域
- **区**：点误区 / 片误区 / 全域区
- **判别意义**：
  - 点误区 → 单点错，外置锚足够，域直接供值即可
  - 片误区 → 成片错，说明锚的取值本身有问题，供值也救不了
  - 全域区 → 说明**域的边界划错了**，这不是锚的问题，是身体的问题
- **与漏检的关系**：6 例漏检很可能不是"阈值太松"，而是这几例落在片误区——阈值收紧能多抓几个，但抓不住成片的。

### 5. 时间道（未度量）

- **度量**：锚点自身的时效性——这条锚会不会过期，以什么速度过期
- **区**：恒常区 / 渐变区 / 骤变区
- **判别意义**：
  - 恒常区（光速、珠峰高度、一年天数）→ 锚可永久外置，一次写入终身有效
  - 渐变区（人口、GDP、城市排名）→ 锚必须带时间戳，供值时先看时点
  - 骤变区（股价、天气、在线人数）→ **根本不适合外置锚**，需要另一套机制
- **这是当前结论最大的边界**：10 条锚点几乎全在恒常区。由此得出的所有数字，只能在恒常区内成立。把它外推到渐变区或骤变区，属于越界使用。

## 三、五道合起来才是身体

五道不是五个并列的功能，是**五条轴张成一个空间**。仂域是这个空间里被划出来的那些区。

### 结构长什么样

```
                强度 ─── 量道区 │ 位道区 │ 界道区
                方向 ─── 偏大区 │ 等当区 │ 偏小区
                速度 ─── 速敛区 │ 缓敛区 │ 不敛区
                空间 ─── 点误区 │ 片误区 │ 全域区
                时间 ─── 恒常区 │ 渐变区 │ 骤变区
                              ↓ 交叉
        求存域 / 行域 / 待域 / 悔域（按需再划）
```

现在的"域"是强度道上的三个切片。**划完五道，每一个区都是五道坐标的交点**，处置方式由五维坐标共同决定，而不是由 L 一个数决定。

### 为什么这才叫身体

身体有三层含义，五道区划是第二、三层的地基：

1. **身体是数据库** —— 库里存的就不该只是一个值，而是这个值在五道上的**坐标**。存"8848"不够，要存"8848，恒常区，点误区，速敛区"。判定规则外挂，不写在库里。
2. **身体有边界** —— 边界不是一个圈，是五道张成的空间里划出的那片区域。之内：锚点、仂感头、门控、门控决策；之外：分词、嵌入、神经网络、输出，原样运行。
3. **身体承载执行** —— 心是触发器（内生合法），域是身体（承载与执行，必须外置锚）。执行什么，由落在哪个区决定。幻觉不看心，看域。

**一句话**：现在的仂域是一条刻度尺；划完五道，它才是一副骨架。

## 四、下一步工作：顺序与成本

不能五道齐头并进——成本差着数量级。按"先便宜后昂贵"排：

| 序 | 工作 | 数据来源 | 需要重跑吗 | 成本 |
|:--:|---|---|:--:|:--:|
| 1 | **补回方向道**：去掉 `max()`，改符号度量，重判所有例 | 现有 JSON | ❌ 离线重判 | 低 |
| 2 | **提取速度道**：从每例 3 遍的 L 序列算 `ΔL/Δn`，划速敛/缓敛/不敛 | 现有 JSON | ❌ 离线提取 | 低 |
| 3 | **收紧量道阈值**：0.003 太松，结合方向、速度重定 | 现有 JSON | ❌ 阈值扫描 | 低 |
| 4 | **划空间道**：需多锚点同时注入的新实验 | 新实验 | ✅ | 中 |
| 5 | **划时间道**：扩充锚点集，纳入渐变类与骤变类 | 新实验 | ✅ | 高 |

前三步**今天就能做，且不用碰模型**。40 例 × 3 遍的原始 JSON 已经在手，离线重判即可。

第 4、5 步才需要上机。

### 一个必须先回答的问题

在动手划区之前，得先定：**区是按阈值切，还是按性质分？**

- 按阈值切（现在的做法）：简单，但阈值是拍的——0.003 太松就是拍出来的后果。
- 按性质分（本文倾向）：区与区之间应该有**性质跃迁**，不是数值渐变。比如"能不能收敛"是性质，"收敛多快"是程度。

我倾向后者。**阈值是从性质里推出来的，不是先拍阈值再往里塞数据。** 但这一步要你定，我不替你定。
